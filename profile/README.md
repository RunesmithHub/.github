# Runesmith Hub

Plugins for [Runesmith](https://github.com/RunesmithHub/Runesmith), built from open source on GitHub and published with signed metadata.

- **Find and install plugins** on the hub website or in Runesmith's plugin manager.
- **Publish a plugin**: read the publishing guide on the hub website, then register it in [registry](https://github.com/RunesmithHub/registry).
- **Report a malicious plugin** privately through [the registry's security reporting](https://github.com/RunesmithHub/registry/security/advisories/new).

| Repository | What it holds |
| --- | --- |
| [registry](https://github.com/RunesmithHub/registry) | Every publisher, plugin, version and moderation decision, and the automation that publishes them |
| [hub](https://github.com/RunesmithHub/hub) | The hub's .NET libraries and the `rshub` tool plugin developers use to check their plugins |
| [website](https://github.com/RunesmithHub/website) | The hub website |
| [packages](https://github.com/RunesmithHub/packages) | Published plugin packages |
