# Security

Please report security problems privately, never in a public issue.

- **A malicious or vulnerable plugin, or a problem with the hub**: use [private vulnerability reporting](https://github.com/RunesmithHub/registry/security/advisories/new) in the registry.
- **A problem in Runesmith itself**: follow [Runesmith's security policy](https://github.com/CodeByDylan/Runesmith/security/policy).

We acknowledge reports within one business day.
